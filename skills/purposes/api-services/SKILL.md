# Назначение: API и сервисы

Сервисы и интеграции: контракты, надёжность, совместимость с потребителями.

## Что делаю

- Держу контракт (схема, коды, версии) совместимым для потребителей.
- Проверяю поведение на ошибках и повторах, а не только на успешном ответе.

## Критерий готовности

- Контракт описан, потребители не сломаны, ошибки и повторы обрабатываются явно.
