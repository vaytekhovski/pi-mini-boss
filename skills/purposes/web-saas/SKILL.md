# Назначение: веб-приложение / SaaS

Работа над продуктом для конечных пользователей: интерфейс, аккаунты, оплата, нагрузка.

## Что делаю

- Держу в фокусе пользовательский сценарий целиком: UI → API → данные.
- Считаю мультитенантность, платежи и нагрузку частью решения, а не «потом».

## Критерий готовности

- Сценарий пользователя проходит целиком, а состояние (аккаунт, оплата) остаётся консистентным при ошибке.
