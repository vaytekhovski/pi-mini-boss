# Назначение: библиотека / CLI / npm-пакет

Публичный инструмент для других разработчиков.

## Что делаю

- Отношусь к API как к контракту: версии, обратная совместимость, документация.
- Проверяю установку и первый запуск на чистой машине.

## Критерий готовности

- Пакет ставится и работает по документации с нуля; ломающие изменения помечены версией.
